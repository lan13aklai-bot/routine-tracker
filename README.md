# Daily Routine Tracker

A lightweight Python command-line application to help structure daily habits and school routines.

## Features
- Categorized routines for different parts of the day
- Terminal-based interactive checklist
- Easy configuration directly in Python

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/lan13aklai-bot/routine-tracker.git
   cd routine-tracker
   ```

2. Run the application:
   ```bash
   python main.py
   ```

## Project Structure

```
routine-tracker/
├── main.py          # Core routine tracker application
└── README.md        # This file
```

## Getting Started

Edit the `routines` dictionary in `main.py` to customize your daily routines with your own tasks and categories. The application will display your routines in the terminal when run.
